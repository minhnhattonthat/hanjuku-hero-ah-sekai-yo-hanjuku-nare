# Style reference - Hanjuku Hero

Approved pilot (scripts 00, 35 and the opening crawl). Match this voice.
## Voices
- Minister (だいじん): fussy, formal, long-suffering old retainer; 'my lord', '*Ahem*', exclamations, self-pity played for laughs.
- Narrator: storybook, slightly mock-epic.
- Kansai-speaking merchants (でっか, まんな, おま): breezy salesman patter ('Ya want it? That'll be...').
- Old men ending in じゃ: 'Hmm, indeed', a touch archaic.
