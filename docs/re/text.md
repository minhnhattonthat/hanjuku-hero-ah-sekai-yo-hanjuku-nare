# Text RE notes (Hanjuku Hero, SFC, 1 MiB LoROM)

Base ROM: `Hanjuku Hero - Ah, Sekai yo Hanjuku Nare...!! (Japan).sfc`, 1,048,576 bytes,
CRC32 d191ad46, MD5 eaab71f99f9f45dfea1fbbf493222999, SHA-1 4edad4a8a8e3ab6117171c48ce2a332757ed3e2f.
Header at $7FC0 "HANJYUKU HERO", map 20 (LoROM), size 0A (1 MiB), SRAM 03.

## Earlier patch (rom/ref, reference only)
Dragoon-X Translations v0.010 (Dec 2000, unfinished, romhacking.net translations/366): "barely playable,
no story translated". Diff vs original (7.6 KB, 19 runs):
- $1C:E400-E93F (file 0xE6400): font tiles 0x40-0xA3 replaced by ASCII A-Z a-z, digraphs li/il/ll (74-76),
  punctuation . , ' ! ? (77 78 7C 7D 7E). Proves English renders fine through the game's own 8x8 font.
- file 0xD3E0C-0xD40C8: a few lines of event script 0x2F-0x31 (pool/castle chatter), command bytes kept.
- file 0xFB6F3-0xFBFF2: menu/system messages (null-terminated, 1A = newline), partly English.
- file 0xFCE42-0xFCF85: the opening crawl (script 0xD3, cmd 1D text).
- file 0xC840-0xD62F (bank 01): unknown 3.5 KB (graphics/code, not studied yet).
Its English is loose; we reuse only its findings.

## Font and encoding (`tbl/jp.tbl`, generated by `tools/mktbl.py`)
- 8x8 2bpp font at file 0xE6000 ($1C:E000), 16 bytes per tile, tile = code. Rows: 40-9F kana pairs
  (katakana, hiragana) in ハは ヒひ order, A0-AF small kana/punct, B0 。, B1-B9 ABXYLRHPG, BA-C3 digits.
- Voiced kana are text codes only: C4-EC = glyph (code-0x84) + dakuten tile C4 on the row above;
  ED-F6 = glyph (code-0xAD) + handakuten tile C5 ($04:92BC). Each text line therefore uses 2 tile rows.
- 3C ” 3D ♪ 3E ♥ 3F 〜 (glyphs 38-3B egg/sword/boot icons). FF = space.

## Event scripts (story, castle and battle chatter)
Interpreter in bank $04 (`$04:8871` load, `$04:897B` fetch). Script id in `$08D0`:
- 00-3F bank $1A table $1A:8000; 40-6A bank $1B table $1B:8000 (id-40); 6B-A9 bank $1C $1C:8000 (id-6B);
  AA-FF bank $1F table $1F:C000 (id-AA). 16-bit pointers inside the bank.
- Script = actor records (4 bytes: sprite, x, y, flags) until FF, then a byte stream.
- Bytes: 00 / F7 end; 01-0F select actor (n-1); 10-39 and F8-FE commands; 3A-F6 and FF text chars.
- Arg counts in `tools/script.py` (ARGS, SUB14). Notable: 14 xx = system sub-op (table $04:FD1B; 14 19 n = goto
  script n, 14 1A n ids.. = random goto); 19 = two 6-char choice labels; 33 = 24-byte buffer (3 x 8-char labels or
  data); 2E n = run n sub-commands at once; 1D = opening-crawl renderer (text, 1A newline, ends on <3A).
  F9-FE print names (no args), F8 n prints string n.
- Dialogue control: 1A newline, 1B new page?, 1C wait for key, 18 close window (TBD in marker build).
- Scripts often end F7 00 or with a goto; bytes after the parsed end up to the next pointer are kept verbatim.

## Other text (survey)
- Fixed 8-byte name tables, 00-padded, bank $17: monsters 0xB8000, generals 0xB8400, attacks 0xB8800-0xB90FF,
  commands 0xB9100, status 0xB9180, hobbies 0xB9200..., eggs 0xB9600, attitudes 0xB9680.
- Countries/castles: 0xC6180 (8 bytes, FF-padded).
- Battle messages: null-terminated, 0xB9700-0xBFFFF (codes 01-0F name/number slots, 1A newline, 2B xx wait,
  3C quote). Pointer tables TBD.
- Menu/system messages: 0xFB6F0-0xFBFFF (null-terminated, 1A newline). Window templates with labels: 0xFB400.

## Engine changes (asm/main.asm) and build layout (build.py)
- ROM expanded to 2 MiB; tables at $20:8800 (ScriptTab 256x3), $20:8B00 (MsgTab 72x3), $20:9000 (BtlTab 1152x3);
  text data packed from bank $21; title art $3E:8000 (+ copyright sprite tiles $3E:B880).
- Hooks: $04:8871 ScriptLoad (event-script id -> long ptr), $04:E40B MsgLoad (menu messages), $03:CCE5 BtlLoad
  (battle messages), $00:F09A SysFetch (bank-01 printer: code 01 lo hi bank = far jump; every original string start
  is overwritten with a jump to its English), $09:F2CE TitlePatch (mode-7 title tiles + copyright sprites).
- In place: name tables (8 bytes; two-letter ligature tiles 8A-B0 for long names), raw tile templates and name-entry
  grids (tools/rawtext.py), yes/no labels $04:FC35, password pieces $1F:B24D, choice labels in script commands
  19/33 (script/choices.json).
- Windows (measured): event dialogue 26 cols x 4 lines (auto-wrap at 26, scrolls); castle menu box 26 x 2;
  bank-01 message box 27 x 2 (no auto-wrap); yes/no box covers cols > 18; 3-way box cols > 15; castle-discovery
  pop-ups 13 wide; opening crawl 26 cols (no digit 9: >= C3 is drawn as a voiced kana there).
- Codes: 0x3C is drawn on the mark row (JP closing quote) - English uses 0x89 for '"'. Event command 36 prints a
  general's name (8 wide). Battle codes 0B-0F are effects (no width), 01-07 inserts (names/numbers).
