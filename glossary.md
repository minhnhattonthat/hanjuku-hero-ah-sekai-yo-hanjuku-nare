# Glossary - Hanjuku Hero: Ah, Sekai yo Hanjuku Nare...!! (SFC, Square 1992)

Binding for every translator and reviewer. Agents propose additions in reports; only the controller edits this file.

## Rulings (pre-approved by the user, 2026-10-16)
- Honorifics: dropped, conveyed through register (〜さま -> "my lord"/"sire" where it is an address; else drop).
  Name order: given name first.
- Romanisation: no official English release exists; earlier fan patch (Dragoon-X 0.010) only covers menus.
  Use natural English for pun names, modified Hepburn for plain Japanese names.
- Credits: English. Graphics text (title subtitle, menus, banners): in scope.
- Abbreviations: none. Full names and terms; engine work before cutting meaning. Flag `LONG:` if it can't fit.
- Register: broad comedy, Square self-parody (FF jokes). Keep jokes and wordplay punchy; adapt, don't explain.

## Style rules
- Speaker prefix: the Japanese puts the speaker before 「 (e.g. だいじん「...). Write `Minister: ` then the line.
  Lines that start with 「 and no name: just the line (no quote marks). A leading full-width space in the JP
  (continuation of the same speaker) may be dropped.
- Punctuation: ‥ / ‥‥ -> `...`; ！！ -> `!!`; ！？ -> `!?`; 〜 (long vowel) -> stretch the word (`Sooo`), or `~`
  where it is a sung/cute note; ♪ and ♥ may be kept. ” (battle-quote mark) is not available: use `"`.
- No Japanese or full-width characters; ASCII only plus ♪ ♥ ~.
- Numbers: digits are fine. No suffix after a variable ({hero}, {nameA}..): write "No. 1", not "1st".
